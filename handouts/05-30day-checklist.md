# 配布資料 ⑤｜30日チェックリスト（Insta代行者版・2レベル）

**使い方**：講義翌日をDay 1とする30日プログラム。**Level 1（自分の集客Threads）** と **Level 2（クライアント向けサービス化）** を並行で走らせる。花嫁アカ実測（n=245）に基づく数字ベンチマーク付き。

**前提**：受講者は Insta 運用経験がある／これから代行事業を始める。

---

## Day 0（講義当日）

- [ ] 配布資料①でプロフィール一行を書いた（**代行者としての集客用**）
- [ ] LINE公式の登録特典を1つ決めた（推奨：「Insta＋Threads運用診断シート」PDF）
- [ ] Threadsアカウントを作った or ログインした
- [ ] **既存Instaクライアントの中から Threadsセット提案候補を1社選定**
- [ ] 配布資料⑥（提案書テンプレ）と⑦（月次レポテンプレ）を保存済

## 絶対にやらないことリスト

- [ ] 自動投稿ツールを導入しない（差別化の要）
- [ ] 10時間後コメントを他人 or ツールに代行させない
- [ ] 数字を毎日見ない（週1・日曜21時のみ）
- [ ] 「今日伸びなかった」で凹まない（中央値579という現実）
- [ ] **クライアント提案時に成果保証で単価を下げない**（"3ヶ月で最低1投稿が5,000views" くらいで十分）
- [ ] **Threads単体プランで受注しに行かない**（必ずセット提案から入る）

## 60日目・90日目にすること（宿題）

### Day 60
- **Level 1**：プロフィール2回目のチューニング。伸びた投稿から最強フックを抽出
- **Level 2**：クライアント2社目の月次レポ①納品。**単価アップ or セット化率アップ**の実行

### Day 90
- **Level 1**：Instagramとの連携を検討開始（自分の集客動線として）
- **Level 2**：3社目クライアントを稼働。**Threads単体 → セットへのアップセル**を1社で成功させる

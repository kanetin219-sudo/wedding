# 配布資料 ①｜プロフィール一行テンプレ

**使い方**：講義中のワーク①（3分）で、下の空欄を埋めるだけ。150字紹介文はそのままThreadsに貼れる状態にする。

---

## Step 1 ｜一行で決める（30秒）

```
【私】は【誰】に向けて【何】を発信 → 【どうしてほしい】に来てほしい
```

### 記入例（花嫁アカ `@don__wd` の場合）

> 【卒花の私】は【プレ花嫁】に向けて【結婚式の節約・後悔しないコツ】を発信 → 【プロフのLINEに登録して無料テンプレをもらいに】来てほしい

### あなたの一行

```
【                】は【                】に向けて【                    】を発信

→ 【                                            】に来てほしい
```

---

## Step 2 ｜プロフィール4点セット（2分半）

| 項目 | ルール | 記入 |
|------|--------|------|
| **名前** | 肩書き＋固有名（例：卒花の駆け込み寺｜don） | |
| **アイコン** | 顔 or ブランドロゴ、背景1色 | |
| **150字紹介文** | 結論ファースト＋数字＋実績＋CTA | ↓下枠に |
| **リンク** | LINE公式 > LP > Instagram の優先順で**1本** | |

### 150字紹介文の型

```
[肩書き]／[実績を1行]
[誰に何を発信するかを1行]
[固有価値を数字で1行]
👇 [CTA] は下のリンクから
```

### 記入枠（150字以内）

```
_________________________________________________
_________________________________________________
_________________________________________________
_________________________________________________
```

---

## Step 3 ｜NGチェック（30秒）

投稿ボタンを押す前に、以下3つのどれかに当てはまったら書き直し：

- [ ] 「日々のことを書きます」→ **誰にも刺さらない**
- [ ] 絵文字 5個以上 → **検索・要点把握を殺す**
- [ ] リンクが2本以上 or ゼロ → **導線が破綻**

---

## 参考：花嫁アカ `@don__wd` の実プロフィール構成

- 肩書き：卒花目線でプレ花嫁向けに発信
- 記事の型：＼◯◯／のフォーク型見出し＋番号付きリスト＋300-499字
- リンク：LINE公式1本
- 2023-07から3年運用で245投稿、最高80,582views

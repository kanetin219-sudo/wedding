# 配布資料 ③｜週7本カレンダー

**使い方**：曜日ごとに"型"を固定する。日曜21時にまとめて7本書き、月〜日で1本ずつ手動投稿（自動投稿は最初の90日は禁止）。

**なぜ木曜21時が"勝負曜日"か**
花嫁アカ245投稿実測：
- 木曜の avg views **5,743**（次点火曜 3,153 の 1.8倍）
- 21時台の avg views **8,519**
- 300-499字帯の avg views **3,503**（次点<100字の 2,594）

→ **木曜21時×300-499字**が三重で最強。この日だけは絶対に外さない。

## 運用ルール（実データ準拠）

1. **投稿時刻は 21:00 JST 固定**（花嫁アカ実測で avg 8,519）
2. **文字数は 300-499字を狙う**（実測で avg 3,503。100-299字は avg 700-1,032 で最悪）
3. **投稿から30分は返信できる状態にいる**（初速リアクションがアルゴの再点火に効く）
4. **10時間後に自分でコメント**を必ず入れる（返信あり投稿は views 3.89倍・花嫁アカ実測）
5. **数字を見るのは日曜21時のみ**（インプ／いいね率／プロフクリックの3指標）

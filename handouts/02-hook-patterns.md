## パターン別・詳細と実例

### ①【衝撃】常識破壊系

**基本テンプレ**
```
【衝撃】プレ花嫁の9割が知らない〇〇のワナ
（続きは10時間後にコメントで書きます）
```

**効く理由**：知的好奇心フック → 保存＆コメントを稼ぐ。
**注意**：「9割」の統計はふわっとOKだが、後の展開で必ず根拠を1つ以上出す。

---

### ②【本音暴露】炎上一歩手前系

**基本テンプレ**
```
正直、これ言うと業界の人に怒られるんですが……
◯◯って、実は要らないです。
```

**効く理由**：業界タブーを1人称で暴くと、共感リプが着火する。返信ありは views 3.89倍（花嫁アカ実測）。

---

### ③【権威訴求】◯年やってわかった系

**基本テンプレ**
```
◯年◯◯業界にいて、たった1つだけ確信していること。
それは──◯◯です。
```

**効く理由**：時間軸で権威を作る。「経験年数×固有価値」を数字で1行に。

**花嫁アカTop3実例**（56,932 views, 508字, 2025-05-14）
> ヘアメイクリハで必ず聞いてほしい質問リスト
> 「当日イメージと違った…」って後悔しないために、これ全部チェックして！

→ 権威＋番号付きチェックリスト＋500字超。1,100いいねを獲得。

### ④【結果訴求】◯日でこうなった系

**基本テンプレ**
```
◯◯を◯日続けたら、◯◯がこうなりました。
before / after の写真とか無いけど、体感で言うと──
```

**効く理由**：期間 × 変化の具体性。beforeが無くても「体感」でOK。

### ⑤【失敗談】昔の私に教えたい系 ← **花嫁アカ最強型**

**基本テンプレ**
```
【失敗談】昔の私に教えたい◯つのこと
① 〇〇 → 実は◯◯だった
② 〇〇 → もっと早く知りたかった
③ 〇〇 → これで◯万円損した
（続きは10時間後にコメントで）
```

**効く理由**：失敗の告白は共感の最強フック。**花嫁アカのTop5中3本がこの型**。

**花嫁アカTop1実例**（**80,582 views**, 470字, 2025-04-03）
> 結婚式って、正直"後から気づく節約ポイント"がめっちゃある。
> 私が実際にやって「もっと早く知りたかった…」って思った節約どころ、正直にまとめます☺️
> 1. 招待状：紙と切手で数万円。LINEでも……

→ **卒花目線＋失敗告白＋番号付き節約リスト＋470字**。バズ倍率 27.81倍アカの最高峰。

**花嫁アカTop5実例**（25,432 views, 448字, 2025-07-04）
> 卒花に聞いたやらなきゃよかったDIY 7選💦
> 節約とこだわりのつもりが…気づけば徹夜と疲労と後悔…
> ① プロフィールブック全部手作業……

### ⑥【比較】対立煽り系

**基本テンプレ**
```
＼◯◯って結局◯◯派？◯◯派？／
実は選び方で満足度が変わる、その理由は──
```

**効く理由**：二項対立で「自分はどっち？」を思わず考えさせる。フォーク型見出し `＼◯◯／` は花嫁アカで頻出。

**花嫁アカTop2実例**（**74,467 views**, 358字, 2026-04-16）
> ＼結婚式って何月が正解？／
> 実は季節選びで満足度かなり変わる
> 🌸 春（3〜5月）
> ◎ 気候が良くて人気No.1……

→ フォーク型＋季節比較＋◎△記号でスキャナビリティ最強。7万views到達。

**花嫁アカTop4実例**（25,794 views, 366字, 2026-02-21）
> ＼卒花が正直に言う、節約して後悔したこと／

→ フォーク型＋失敗告白のハイブリッド。

### ⑦【逆張り警告】◯◯だけはやめて系

**基本テンプレ**
```

```

## 10時間後コメントで再点火

冒頭フックを投稿したら、**10時間後**に自分の投稿にコメント形式で"続き"を書く：

```
投稿から10時間後 →
「（コメント）続きです。
①〜⑦のうち、私が一番大事だと思うのは⑤。
理由は──」
```

**根拠**：花嫁アカ実測で **返信のある投稿は views 3.89倍**（8,256 vs 2,122）。フックが呼び水として機能している1次証拠。
